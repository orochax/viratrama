# Marcadores de funcao

- Diametro final: `20 mm`; retrato util: `18,4 mm`.
- `MARCADORES_FRENTE_A4.svg`: 12 combinacoes de funcao e avatar.
- `MARCADORES_VERSO_A4.svg`: verso espelhado para impressao frente e verso.
- Imprimir a 100%, sem ajustar. Fazer prova de registro antes do lote.
- Cor e letra no verso permitem identificar a funcao sem depender apenas da cor.

Os SVGs vinculam os retratos em `public/media/roles`. Para enviar a uma grafica,
abrir no navegador com o repositorio completo e exportar para PDF incorporando as imagens.
