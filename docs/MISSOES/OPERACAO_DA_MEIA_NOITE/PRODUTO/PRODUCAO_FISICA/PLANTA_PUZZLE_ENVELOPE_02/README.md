# Planta-puzzle PZ-02

- `PLANTA_INCOMPLETA_A3.svg`: imprimir em papel A3, paisagem, 100%, sem ajuste.
- `TRANSPARENCIA_CORREDORES_A3.svg`: imprimir em acetato A3, paisagem, 100%, sem ajuste.
- Conferir os quatro registros vermelhos sobre uma mesa de luz antes da producao.
- A camada nao escreve a resposta. Ela determina a ordem de leitura dos quatro grupos de marcas.
- A resposta validada pelo servidor e `2317`; esse valor nao deve constar em nenhuma arte entregue ao jogador.

Antes do lote, imprimir uma prova dos dois arquivos na mesma impressora e medir o quadro externo: `400 x 277 mm`.
